# vitals: Large Language Model Evaluation

A port of 'Inspect', a widely adopted 'Python' framework for large
language model evaluation. Specifically aimed at 'ellmer' users who want
to measure the effectiveness of their large language model-based
products, the package supports prompt engineering, tool usage,
multi-turn dialog, and model graded evaluations.
